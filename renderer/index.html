WhatsApp

WhatsApp Web runs inside AV Courier. Link it once with the QR code (WhatsApp on your phone → Linked devices). Incoming messages are read from WhatsApp’s notifications and unread chats; replies are typed into the chat for you. Muted chats do not raise notifications.

Gmail

Replies go into the same email thread. Log in with a Google App Password (Google Account → Security → App passwords), or sign in with Google when App Passwords are not allowed on a work account.

Needs a one-time “Desktop app” OAuth client from your organisation’s Google Cloud (steps in the README, section Sign in with Google). Load the JSON file you downloaded for it (or paste its ID and secret), then sign in: Google’s page opens in your browser and AV Courier never sees your password.

Claude (reads requests and screenshots)

Optional. Without it, requests are read with patterns (drive/tape numbers, dates, key words). With it, loosely written requests, mixed languages and pictures (posters, screenshots, programme lists) are understood too. Only the request text and its pictures are sent; the catalogue stays on this PC.

Phone (AV Courier for Android)

Lets the Android app on the same Wi-Fi see requests, reply, queue copies and start tapes. When WhatsApp Web on this PC is not linked or fails, “data is ready” messages are handed to the phone to send. Only phones paired with a code shown here can connect; nothing is reachable from the internet.

Never a request

Messages from these are never treated as data requests, here and on the phone: WhatsApp verified businesses (✔, found by their badge in WhatsApp's chat list) and senders you chose to ignore (💬 WhatsApp, ✉ email). ✕ undoes one.

Other computers

Running AV Courier on more than one computer? Turn this on in each, and a request you reply to, copy or close on one shows as done on the others. Only request status is shared; each computer keeps its own queue, drives and catalogue. Keep “send automatically when a copy finishes” on for one computer only.

Uses the Gmail address and App Password already saved on the Channels page: same account on every computer. Updates are kept in a Gmail label “AV Courier sync”, already read and never in the inbox. Nothing is sent to anyone, and it takes a few KB a month.
